# Tracker Agent Notes

This is the local issue repository for the Domowik project in the parent
directory. Follow `../AGENTS.md`, especially its clean-room, licensing, ADR,
and formatting rules. If the parent repository is unavailable, do not perform
implementation or behavioral study work from these issues alone.

Keep the index synchronized with issue state and location. Tracker commits use
Conventional Commits, for example:

```text
chore(issue-0012): mark spatial index work blocked
```

Before this repository is published independently, replace relative links with
stable URLs and add a complete Apache-2.0 `LICENSE` file.
