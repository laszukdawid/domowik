# Tracker Agent Notes

This directory is the tracked-file backlog of the Domowik repository, not a
separate repository. Follow `../AGENTS.md`, especially its clean-room,
licensing, ADR and formatting rules. The root Apache-2.0 license covers issue
text. Relative links are appropriate when publishing the repository on GitHub.

Keep the index synchronized with issue state and location. Tracker commits use
Conventional Commits, for example:

```text
chore(issue-0012): mark spatial index work blocked
```

Read `CURRENT-BACKLOG.md` and an issue's newest Current disposition before
acting on older notes. Dated reports, local machine paths and old commit IDs
are historical evidence, not current assignments or reproducible setup steps.
Keep acceptance criteria; explicitly reconcile superseded claims rather than
silently removing unfinished obligations. `In Progress` means actively being
worked on; use partial scope for delivered work with residuals, and Blocked
only for a named external decision or input.
